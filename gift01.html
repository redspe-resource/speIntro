程式題到底在做什麼？

把題目的規則整理成電腦能執行的步驟。

題目給資料

例如：數字、成績、文字、時間或資料筆數。

依規則處理

例如：相加、比較、判斷、重複計算或整理資料。

暖身問題

先從生活問題開始

小明有 12 顆糖果，小華又給他 8 顆。小明現在共有幾顆糖果？

先不要急著回答。想一想：題目給了哪些資料？最後要得到什麼？

請寫下：
題目提供的資料：__________
題目最後要的答案：__________
IPO 第一步

I

Input：輸入，電腦先得到資料

糖果題的 Input

12、8

這是題目提供的兩個數字。

讀題時要問

「題目給了我什麼資料？」

資料可能是數字、文字、成績、座號或資料筆數。

練習：若題目說「輸入矩形的長與寬」，Input 是什麼？
IPO 第二步

P

Process：處理，電腦依規則做事

糖果題的 Process

12 + 8

把兩個數量加起來。

讀題時要問

「資料要怎麼變成答案？」

常見處理包括：計算、比較、判斷、排序與重複處理資料。

練習：若題目是「輸入兩個整數，輸出較大的數」，Process 是相加還是比較？
IPO 第三步

O

Output：輸出，交出題目要的答案

糖果題的 Output

20

最後交出的答案是 20。

讀題時要問

「最後要印出什麼？格式是什麼？」

答案正確之外，輸出格式也必須正確。

注意：如果題目只要求輸出 20，不要自行輸出「答案是：20」。多出來的文字可能造成格式錯誤。

先認識必要部分

第一支程式的四個重點

#include <iostream>讓程式可以使用輸入和輸出工具。
using namespace std;有這一行，就可以直接寫 cin 和 cout。
int main() { ... }程式從這裡開始執行。大括號內是程式要做的事情。
cout << ...把資料輸出到畫面上。
目前先記住：cout 代表「輸出」。
示範題

題目：兩數相加

輸入兩個整數，輸出它們的總和。

範例輸入7 12
範例輸出19
先完成 IPO：
Input：____________
Process：____________
Output：____________
把題目拆開

兩數相加的 IPO

Inputa、b

兩個整數

Processa + b

將兩數相加

Outputsum

輸出總和

變數盒子

a 放第一個數字，b 放第二個數字，sum 放計算後的答案。

接下來要做什麼？

建立變數、讀入資料、計算、輸出答案。

把 IPO 翻成 C++

兩數相加：完整程式

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    int sum = a + b;
    cout << sum << endl;

    return 0;
}
int a, b;準備兩個整數變數。
cin >> a >> b;從鍵盤讀入兩個數字，依序放入 a 和 b。
int sum = a + b;計算 a + b，把結果放入 sum。
cout << sum << endl;把總和輸出到畫面。
操作：貼到 Code::Blocks，按 F9。先輸入 7 12，確認得到 19。

總秒數換算為時、分、秒

輸入一個整數，代表總秒數。請輸出其中有幾小時、幾分鐘與幾秒，三個數字中間以一個空格分開。

範例輸入3671
範例輸出1 1 11
hours
= total / 3600
remain
= total % 3600
minutes
= remain / 60
seconds
= remain % 60
拆解方法：先算完整小時；從剩下的秒數算完整分鐘；最後留下的就是秒數。
除錯診所

這段程式哪裡有問題？

目標：輸入兩個整數，輸出它們的總和。請找出至少兩個問題。

#include <iostream>
using namespace std;

int main() {
    int a, b 
    cin >> a >> b;
    cout << "答案是：" << a + c << endl;
    return 0;
}
找錯任務：
1. 哪個地方會讓程式無法編譯？
2. 哪個變數有問題？
3. 哪段輸出在競賽中可能被判錯？

問題 1：int a, b 後面少了分號 ;。

問題 2：c 沒有被宣告，應改為 a + b。

問題 3：若題目只要求數字，答案是： 是多餘輸出，可能造成格式錯誤。
