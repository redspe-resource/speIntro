回顧

先回顧：你還記得嗎？

第四週的判斷是兩路的：

問題一：輸入 20 25 18，總點數是多少？畫面印出什麼？

核對答案

總點數 68（20+25+18=63，加 5），印出「過關」。

問題二：if 和 else 各在什麼時候執行？

核對答案

條件成立（總點數達 60）走 if，不成立走 else。每次執行只走一邊。

新規則

本週新規則：三個等級

校園闖關的分級規則：

金牌總點數 90 以上（含）例如：95、100、305
銀牌總點數 60–89例如：68、75、89
未過關總點數未達 60例如：41、59
注意：門檻有兩個——90 和 60。獎勵仍然固定加 5 點。總點數可能超過 100：輸入 100 100 100 得到 305，一樣是金牌。

備課與帶領：5–10 分鐘。兩個門檻 90/60 要寫清楚。明確說 305 也是金牌，避免學生以為總點數最多 100。

新語法

新語法：if / else if / else

把第四週的 if / else 區塊，換成這個三級版本：

C++
if (totalPoints >= 90) {
    cout << "金牌" << endl;
} else if (totalPoints >= 60) {
    cout << "銀牌" << endl;
} else {
    cout << "未過關" << endl;
}
  • 第一個條件成立（總點數 ≥ 90）→ 印「金牌」，後面全部跳過。
  • 第一個不成立，才檢查第二個：總點數 ≥ 60 → 印「銀牌」。
  • 兩個都不成立 → 走 else：印「未過關」。
記住：else if 可以有很多個，但每次執行只會走其中一個分支。
備課與帶領：10–13 分鐘。先讀語法：三個分支各印什麼、什麼時候走。讀完再進下一頁追蹤。

核心觀念

由上往下檢查：第一個成立的贏

追蹤一：總點數 68
68 >= 90 ?不成立，往下一個
68 >= 60 ?成立 → 印「銀牌」
追蹤二：總點數 95
95 >= 90 ?成立 → 印「金牌」，不再檢查
想一想：銀牌那一行只寫 >= 60，為什麼 95 不會印銀牌？因為 95 在第一關就成立了，根本走不到銀牌那一行。
記住：能走到銀牌那一行，代表「≥ 90」已經不成立。所以銀牌實際代表的是 60–89。
備課與帶領：13–17 分鐘。本頁是全週核心。68、95 各追蹤一次，讓學生開口說「第一個成立的贏」。追問：為什麼銀牌代表 60–89？

除錯

為什麼金牌印不出來？

C++
if (totalPoints >= 60) {
    cout << "銀牌" << endl;
} else if (totalPoints >= 90) {
    cout << "金牌" << endl;
} else {
    cout << "未過關" << endl;
}

輸入 28 28 30，總點數 91，畫面卻印出「銀牌」。金牌那一行為什麼永遠印不出來？

顯示修正與原因

91 在第一關 >= 60 就成立了，印完銀牌就停止，後面的 >= 90 永遠檢查不到。把金牌的判斷移到最前面，再用 91 重新測一次。

備課與帶領：36–38 分鐘。先讓學生預測 91 印什麼，再執行。要聽到學生說出「91 在 >= 60 就停了」。
